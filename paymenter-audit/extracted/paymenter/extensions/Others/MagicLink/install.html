MagicLink

v1.0.0 · NEON NEXT GENERATION · Paymenter Extension

MagicLink adds passwordless login to your Paymenter panel. Users enter their email, receive a one-time link, and log in without a password.

Requirements

  • Paymenter v1.0 or later
  • A working mail driver (SMTP, Mailgun, etc.) configured in your .env
  • Admin access to your Paymenter panel

Installation

Step 1 — Download the extension

Download the MagicLink ZIP file. Do not rename the folder inside.

Step 2 — Upload to Paymenter

Option A — Admin Panel (recommended)

  1. Log in to your Paymenter admin panel.
  2. Go to Extensions in the sidebar.
  3. Click Upload Extension (or the + button) and select the ZIP file.
  4. Paymenter will extract the extension into the correct directory automatically.

Option B — Manual upload via SSH/FTP

  1. Extract the ZIP on your computer.
  2. Upload the MagicLink folder to your Paymenter directory at:
extensions/Others/MagicLink/

It should look like this when done:

extensions/Others/MagicLink/ MagicLink.php MagicLinkMail.php Http/Controllers/MagicLinkController.php migrations/ resources/views/ routes/web.php
Important: The MagicLink folder must sit directly inside extensions/Others/. If it's nested deeper (e.g. extensions/Others/MagicLink/MagicLink/) it won't be detected.

Step 3 — Run migrations

SSH into your server, navigate to your Paymenter root, and run:

php artisan migrate

This creates the magic_link_tokens table. If you uploaded via the admin panel, the extension's installed() method may handle this automatically.

Step 4 — Clear caches

php artisan cache:clear
php artisan route:clear
php artisan view:clear

Step 5 — Enable the extension

  1. In the admin panel, go to Extensions.
  2. Find Magic Link Login under the Others tab.
  3. Toggle it on to enable.

Step 6 — Verify

Open your Paymenter login page. You should see a "Sign in with Magic Link" button below the regular login form.

Mail setup

MagicLink sends a login email to users. Make sure your Paymenter .env has working mail settings:

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your-password
MAIL_ENCRYPTION=tls

Test by sending yourself a password reset before going live.

Troubleshooting

Button doesn't appear on the login page

  • Confirm the extension is enabled under Extensions in the admin panel.
  • Run php artisan route:clear && php artisan view:clear.
  • Check the folder is at extensions/Others/MagicLink/ with no extra nesting.

Emails not arriving

  • Check your mail config in .env and test with a password reset email.
  • Look in spam/junk folders.
  • Check storage/logs/laravel.log for SMTP errors.

Token says "invalid" or "expired"

  • Links expire after the configured token expiry (default 15 min).
  • Each link is single-use — requesting a new one invalidates the previous.
  • Make sure the magic_link_tokens table exists (php artisan migrate).

Rate limit hit too quickly

  • Increase the max attempts or rate limit window in the extension settings.

How it works

  1. User clicks "Sign in with Magic Link" on the login page.
  2. They enter their email and submit the form.
  3. A random 64-character token is generated, hashed with SHA-256, and stored in the database with an expiry.
  4. The user receives an email with a one-time login link.
  5. Clicking the link validates the token, logs the user in, and redirects them to their dashboard.
Tokens are stored as SHA-256 hashes — the raw token is never saved. Each token can only be used once.
